## FAQ

**Q: What should I enable first after install?**  
A: Turn on **Kill Switch**, then connect to the closest server for the best speed.

**Q: How do I know encryption is active?**  
A: If the VPN shows “Connected” and routes traffic through the tunnel, you’re protected with **AES-256 encryption** as configured by the client.

**Q: Which server should I pick?**  
A: Start with the nearest location. Switch regions only when you need a specific endpoint. **Global Servers** make this quick.

**Q: Does this keep browsing private?**  
A: The client follows a **No-Logs policy** and is built with a **privacy and security focus**. Always keep the Kill Switch on to avoid leaks on disconnects.
